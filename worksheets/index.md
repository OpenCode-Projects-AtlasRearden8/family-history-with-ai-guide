# Worksheets (Print-Ready)

*The working paperwork for the manual: question banks, worksheets, logs, and
checklists. Print them, copy them into a spreadsheet, or just read them off
a screen — whichever keeps the habit going.*

| Worksheet | Use it for | Used in |
| --- | --- | --- |
| [Interview Question Bank](interview-questions.html) | Ready-made questions for any relative | Interviewing |
| [Interview Worksheet](interview-worksheet.html) | One page per interview session before/after | Interviewing |
| [Photo Inventory](photo-inventory.html) | Mapping who has what photos, and where the gold is | Photos |
| [Source Log](source-log.html) | Logging every claim and its proof | Verification |
| [Verification Checklist](verification-checklist.html) | The five-box ritual before any fact is trusted | Verification |
| [Privacy Log](privacy-log.html) | Who consented to what, and every redaction | Privacy |

## How the worksheets fit a session

- **Before an interview:** print the question bank (+ interview worksheet),
  mark today's top 10, test the recorder, note consent.
- **Within 24 hours:** copy the audio out, name, back it up, fill the
  "after" half, and start a source-log row per new claim.
- **At the scanner:** photo inventory sheet Pass 1 first; scan gold after.
- **Monthly:** run the verification checklist's ten-minute audit and the
  privacy pass if you've drafted new chapters.
